# Dennoko Normal Editor 使い方

VRChat アバター改変向けの、非破壊カスタム法線編集ツールです。  
Unity のシーンビュー上で直観的に法線を調整し、顔の影の落ち方やハイライト、首などの別メッシュ間の継ぎ目（法線割れ）をきれいに整えられます。元のメッシュファイルは書き換えません。

## 必要環境

- Unity 2022.3.22f1 以降
- VRChat SDK
- **NDMF (nadena.dev.ndmf)** — 必須

---

## Quick Start

### 1. コンポーネントの追加
ヒエラルキーで編集したいメッシュ（頭や体など）を右クリックし、`dennokoworks > Dennoko Normal Editor` を選択します。

### 2. 編集モードの開始
Inspector の **「編集」** ボタンを押します。※メッシュにコンポーネントを追加した場合は自動で編集モードに入ります。

### 3. 編集
シーンビューで頂点をクリックして選択し、3Dハンドルで法線を傾けるか、右下のパネルにあるスライダー（「なじませる」「形状を戻す」「揃える」「元に戻す」）を操作します。  
ハンドルを掴んでいる間、マウスホイールで影響範囲（ブラシ半径）を調整できます。

### 4. 編集モードの終了
`Esc` キーを押す（選択中は選択解除、未選択時は編集終了）か、Inspector で「編集終了」ボタンを押します。

## 詳しい使い方

### 1. コンポーネントを付ける

ヒエラルキー上で編集したいメッシュ（SkinnedMeshRenderer / MeshRenderer）を持つオブジェクトを右クリックし、`dennokoworks > Dennoko Normal Editor` を選択します（または Inspector の `Add Component` から追加します）。

- **Renderer を持つオブジェクトに右クリックから追加した場合：**  
  そのメッシュが自動的に編集対象として登録され、**即座に編集モードが有効化**されます。
- **複数のオブジェクトを選択した状態で追加した場合：**  
  選択中のメッシュが**すべて編集対象として登録**されます（例：Face と Body を両方選択して追加すると、首の継ぎ目をまたいだ編集が可能になります）。コンポーネント自体は 1 つだけ、右クリックしたオブジェクト（または最後に選択したオブジェクト）に付きます。
- **Renderer のないオブジェクトに追加した場合：**  
  コンポーネントのみが追加されます。Inspector の「対象を追加」欄から編集したい Renderer を指定してください。

コンポーネントが付いたオブジェクトは、ヒエラルキー上で一瞬ハイライトされます。

あとから対象を増やしたいときは、Inspector の「編集対象」の一番下にある **「対象を追加」の空欄へ、メッシュを持つオブジェクトをドラッグ＆ドロップ**します。複数まとめてドロップすることも可能です。  
頭（Face）と体（Body）を同時に登録しておくと、境界を越えて継ぎ目を自然になじませられます。

### 2. 編集する

Inspector の **「編集」** ボタンを押すと、シーンビューが編集モードになります。

| 操作 | 動作 |
| --- | --- |
| メッシュ上の頂点をクリック | **見えている**頂点のうち、クリック位置に最も近いものを選択（黄色い点が候補、青い円が影響範囲） |
| 3Dハンドルをドラッグ | 選択頂点から法線方向に伸びたハンドルを引っ張り、影響範囲内の法線を減衰させながら傾ける（Tilt） |
| **ハンドルを掴んだままマウスホイール** | **影響範囲の半径を変更（上で縮小、下で拡大 / Blender準拠）** |
| 右下パネルのスライダーをドラッグ | 選択範囲全体に対して「なじませる」「形状を戻す」「揃える」「元に戻す」を適用 |
| `Esc` | 選択解除。もう一度押すと編集終了 |
| 別のオブジェクトを選択 | 編集終了 |

シーンビュー右下のオーバーレイパネルで、半径・減衰・ミラー・各種エフェクトをその場で調整できます。

### 頂点の選択について

**裏側に隠れた頂点は選択されません。** 手前の面に遮られている頂点は候補から除外され、実際に見えている表面の頂点のみが選択されます。

> **注意：** 遮蔽物として判定されるのは**編集対象に登録した Renderer だけ**です。  
> たとえば素体だけを登録して服を登録していない場合、服に隠れた素体の頂点も選択できてしまいます。服も編集対象に追加すれば解決します。

### やり直し（Undo）

**ハンドルを動かす 1 操作、またはスライダーを離す 1 操作が Undo 1 回分**です。`Ctrl+Z` を押すと、直前の編集だけが取り消されます。  
ハンドルを掴んでいる間にホイールで変えた半径も同じ操作に含まれるため、まとめて元に戻ります。

### ハンドル操作中の半径変更

ハンドルを掴んだままマウスホイールを回すと、影響範囲を広げたり狭めたりできます。  
**掴んだだけで、まだ動かしていない状態でも変更できます。** 動かす前に「どこまで巻き込むか」を決めてからドラッグに入れますし、動かした後なら**動かした状態のまま**調整できます。

ホイールは 1 目盛りごとに一定の割合で変化するため、半径が小さいときは細かく、大きいときは大きく動きます。手を離していれば、通常どおりシーンビューのズームになります。

### 3. 選択範囲の法線調整（エフェクトスライダー）

頂点を選択した状態で、シーンビュー右下のパネルにあるスライダーを動かすと、影響範囲内の法線に対して即座にエフェクトをプレビュー・適用できます。

- **なじませる（Smooth）：**  
  範囲内の法線を周囲の頂点と平均化して滑らかにします。UVシームや**別メッシュ間の境界（頭と体の首の継ぎ目など）** も自動的に検出し、境界をまたいで法線を連続的につなぎ合わせるため、首の明暗の割れ目や黒ずみの解消に最適です。
- **形状を戻す（Restore Shape）：**  
  顔全体に球面法線などが転写されて平坦（のっぺり）になりすぎたメッシュに対し、**ポリゴン本来の立体形状から計算された滑らかな法線（Smooth Geometric Normal）** を任意の割合だけブレンドして戻します。スムーズな陰影を崩さずに、鼻筋・唇・目元などの立体感を自然に引き出すことができます。
- **揃える（Flatten）：**  
  範囲内の法線を選択頂点の法線方向（または平均方向）へ均一に揃え、アニメ調のフラットで陰影が出にくい面を作ります。
- **元に戻す（Erase）：**  
  選択範囲内の法線を編集前の状態（0%）へ戻します。部分的にやり直したい場合に使用します。

### 4. 強度マスク（UV0 マスク機能）

Inspector の各編集対象には **「マスク」**（Texture2D）を設定できます。

- メッシュの **UV0 の明るさ（白 = 100%、黒 = 0%）** に応じて、そのオブジェクトへの法線編集の強度を制限します。
- 瞳や眉、生え際など「法線を動かしたくない部分」を黒く塗ったテクスチャを指定することで、ブラシの巻き込みを防止できます。
- グラデーションテクスチャを使うことで、なめらかな効き具合のグラデーションを作成することも可能です。

### 5. そのままアップロード

保存操作は不要です。編集結果はコンポーネントに自動保存され、アバターのアップロード時に NDMF が自動で法線および接線（Tangent）を適用します。元のメッシュファイルが変更されることはありません。

## ブラシ設定

### 半径
影響範囲の広さ（ワールド単位、メートル）です。シーンビューに青い円で表示されます。

### 減衰
中心から離れるにつれて効果が弱まるカーブです。

| 種類 | 特徴 |
| --- | --- |
| スムーズ (Smooth) | 端がなめらか。通常の編集ではこちらを推奨 |
| 直線 (Linear) | 一定の割合で減衰 |
| シャープ (Sharp) | 中心付近だけ強く効く |
| 一定 (Constant) | 範囲内全体に均等に効く（減衰なし） |

## ミラー編集

シーンビューのオーバーレイまたは Inspector でミラーを有効（ON）にできます。

- **ミラー軸：** X 軸（左右対称）、Y 軸（上下対称）、Z 軸（前後対称）から選択できます。通常のアバター編集では X 軸を使用します。
- **対称編集：** ミラーが有効な間に行った操作（傾け・なじませる・形状を戻す等）が、中心を挟んで反対側にも鏡像として適用されます。
- **中心付近の保護：** 中心線のごく近くを編集した場合、左右の影響範囲が重複して二重に変形するのを防ぐため、ミラーは自動的にスキップされ単独編集として処理されます。

## ベイク

編集結果を適用したメッシュを、独立したアセットファイル（.asset）として書き出せます。

- 保存先：**元メッシュと同じフォルダ**
- ファイル名：元メッシュ名に **`_edited`** を付与（同名ファイルが存在する場合は末尾に連番）
- **安全設計：** ベイクは新しいメッシュファイルを生成して選択するだけで、シーン内の Renderer の設定は自動で差し替えません。アセットとして手元に残したい場合や、他プロジェクトへ書き出したメッシュを持ち出したい場合にご利用ください。

## 仕様と制限

### できること
- 頂点法線の傾け（プロポーショナル編集）
- 複数メッシュ間（頭と体など）をまたぐ継ぎ目の法線なじませ（クロス・メッシュ結合）
- スムーズ幾何法線の部分復元（球面法線メッシュの立体感戻し）
- 法線の均一化（フラット化）
- UV0 テクスチャによる編集強度マスク
- 任意の軸でのミラー編集
- NDMF プレビューへのリアルタイム反映（プレイモード不要）
- メッシュのベイク出力
- **接線（Tangent）の自動直交化：** 法線の変化に合わせて接線をグラム・シュミット法で直交化するため、ノーマルマップや異方性反射マテリアルが破綻しません。

### できないこと（意図的に対応していません）
- 頂点や面の追加・削除などのトポロジー編集
- 頂点座標（メッシュの形状そのもの）の移動（形状を変形したい場合は姉妹ツールの **Dennoko Mesh Editor** をご利用ください）
- UV やボーンウェイトの編集

### 頂点インデックスへの依存について
本ツールは、**「元のメッシュの頂点インデックス（頂点番号）」に対して法線差分を保持・適用する仕組み**になっています。そのため、以下の点にご注意ください。

- **FBX の再エクスポート・再インポート：** DCC ツール（Blender等）からメッシュを再出力して頂点数や頂点順が変化した場合、編集位置にズレが生じます。
- **誤変形の安全対策：** メッシュの差し替えや再インポートで頂点数が編集時と異なっている場合、誤った法線が適用されて陰影が崩れるのを防ぐため、**編集の適用は自動的に安全にスキップ**され、警告が表示されます。

### 他ツールとの関係
ビルド時は NDMF の Transforming フェーズ（Modular Avatar の直後）で処理します。  
メッシュの頂点数を最適化する Avatar Optimizer (AAO) よりも先に適用されるため、安全に共存できます。

## トラブルシューティング

### 「NDMF プレビュー未取得」と表示される
NDMF のプレビューが無効になっているか、まだ生成されていません。この状態でも編集は可能ですが、他ツールの変更が反映されていない素のメッシュを編集することになります。Unity の NDMF プレビューが有効になっているかご確認ください。

### 「頂点数が編集時と異なります」と表示される
元メッシュが差し替わったか、FBX の再インポートで頂点数が変化しています。誤った法線が適用されるのを防ぐため適用が保留されています。Inspector の「すべての編集をクリア」で一度リセットし、再編集してください。

### 首の継ぎ目がなじまない
頭（Face）と体（Body）の両方がコンポーネントの「編集対象」に登録されているかご確認ください。両方が登録されていることで、別メッシュ同士の境界頂点を自動結合して一緒に計算します。

### アップデートの確認について
Inspector 最上部に現在のバージョン（`v1.0.0`）が表示されます。GitHub 上に新しいバージョンがリリースされている場合は「更新あり」のリンクが表示され、クリックで配布ページを開けます。右端の `↻` ボタンを押すと手動で最新バージョンを再確認できます。
